# Destructible Tree Pack - Unity Asset Store

Official documentation and support page for the **Destructible Tree Pack** published on the Unity Asset Store.

## Package Contents
* 4 Low-Poly Destructible Trees (Pine, Willow, Baobab, Dead Tree)
* Solid and Pre-fractured Prefabs with configured Colliders and Rigidbodies
* LOD (Level of Detail) setups and Demo Scene included

For questions, bug reports, or support requests, please open an issue in the **Issues** tab above or contact via the Unity Publisher Portal.
